## P2/P3 交付明细

### P2
- `sp-core/net.rs`：TCP 客户端 / TCP 服务端（多客户端并发）/ UDP，与串口同款
  worker 模式（catch_unwind + 同一 ChannelEvent/Command 协议），UI 通道类型下拉切换
- `sp-core/hooks.rs`：mlua（Lua 5.4 vendored）双向钩子。`on_send(data)`/`on_recv(data)`
  返回新数据即替换，nil 透传；工具表 `sp.hex`/`sp.fromhex`/`sp.log`，print 重定向到
  脚本输出面板；脚本编译失败保留旧脚本可用
- `sp-core/plot.rs`：文本模式数值列提取（支持小数/负数/科学计数）、Hex 模式按字节取值；
  最多 3 条曲线、4000 点环形缓冲
- `sp-ui`：Lua 脚本编辑窗口（启用开关/输出面板）、示波器窗口（egui_plot 三色曲线/图例）

### P3
- `crates/serial_monitor` + `crates/serial_monitor_hook`：自 llcom serial_monitor_rs
  （Apache-2.0）迁入工作区；serial_monitor 增加 rlib target 供主程序直接链接；
  build.rs 适配新工作区 target 布局
- `sp-ui` 监听窗口：进程枚举（Toolhelp）+ 目标选择 + COM 号 + 开始/停止；
  注入数据经 C 回调 → crossbeam 通道 → 主接收区显示（TX/RX 方向着色）
- `sp-core/ansi.rs`：ANSI 转义解析（SGR 全套：16 色/256 色/真彩、粗体/斜体/下划线；
  CSI 光标/清屏与 OSC 剥离），接收区"ANSI 渲染"开关

# P4 交付记录（2026-11-25）

### MQTT 通道（rumqttc）
- `sp-core/mqtt.rs`：rumqttc 同步客户端。订阅主题的 Publish payload → Rx；
  发送 → publish 到发布主题（QoS AtLeastOnce）；keep-alive 30s；
  内部收包线程 + 控制线程（client 可 Clone）双线程结构
- UI：通道类型新增 MQTT，可配 Broker / 订阅主题 / 发布主题；标签显示 `sub ⇄ pub`

### WinUSB 通道（rusb）
- `sp-core/usb.rs`：libusb vendored 静态编译（无需额外 DLL）。按 VID:PID 打开设备，
  自动定位第一个 bulk IN/OUT 端点对；bulk 读（20ms 轮询）→ Rx、bulk 写 → TxEcho；
  `list_winusb_devices()` 设备枚举、`parse_vid_pid()` 宽松解析（0x 前缀 / `-` 分隔）
- UI：通道类型新增 WinUSB，输入 `VID:PID`（默认 CH340 1A86:7523）
- Windows 侧仍要求设备驱动为 WinUSB/libusb（Zadig 安装），错误信息已明示

### 多语言（中/英）
- `sp-ui/lang.rs`：`Lang` 枚举 + 翻译表（中文原文为键）；`tr()` 中文直通、英文查表回退
- 工具栏新增语言切换按钮（EN/中），设置持久化（`settings.lang`）
- 已覆盖：通道类型、打开/关闭按钮、接收区开关、发送/清屏/队列按钮、窗口标题、自动日志

### NSIS 安装包
- `installer/serial-pro.nsi`：双语（English + 简体中文）向导、License 页（README）、
  组件页（主程序必选 + 开始菜单 + 桌面快捷方式默认关）、完成页可启动、
  卸载清理（含 taskkill、便携 settings.json、注册表卸载项）
- 构建：`cargo build --release && makensis installer\serial-pro.nsi`
  → `installer/serial-pro-setup.exe`（约 3.9MB）

### 质量数据
- 测试 61 全绿（新增 mqtt broker 解析 2 + usb vid/pid 2 + lang 4）、clippy 0 警告
- release 8.6MB 单 exe（libusb 静态链入，无运行时依赖）
